About CarePlus

An academic project demonstrating modern web technologies in healthcare management

Project Background

Bridging the digital gap in Malaysian healthcare

CarePlus Smart Clinic Management Portal is an academic project developed to address the digital transformation gap in small and medium-sized clinics across Malaysia. According to the Malaysian Healthcare Performance Unit (2023), approximately 65% of private clinics in suburban areas continue to rely on paper-based systems, resulting in operational inefficiencies and longer patient waiting times.

This project demonstrates how modern web technologies can be effectively applied to streamline essential clinic operations, including appointment management, patient record handling, and administrative communication. The system is designed as a functional prototype that showcases practical features tailored specifically to the operational needs of small to medium-sized clinics.

Built using a Hybrid Agile-Waterfall methodology over a 14-week development period, CarePlus integrates core healthcare IT functionalities with user-friendly design principles. The system emphasizes accessibility, data security compliance with Malaysian regulations (PDPA 2010, Act 586), and practical usability for clinic staff with varying levels of technical expertise.

While developed as an academic prototype, the system incorporates industry-standard security measures and follows Ministry of Health (MOH) guidelines for Electronic Medical Records, demonstrating the potential for scalable digital solutions in primary care settings.

Project Aim & Objectives

🎯

Project Aim

To create and build a working model of a Smart Clinic Management Portal that supports key administrative and clinical processes in clinics. The system focuses on user-friendliness, smooth workflow, and secure data storage, incorporating advisory tools such as symptom checking and an internal messaging module to communicate with patients without providing medical diagnosis.

🔭

Development Vision

To demonstrate the use of modern web technologies in a real clinical environment by providing an easily accessible digital solution tailored specifically to the needs of clinics in Malaysia. The system aims to be user-friendly, efficient, and practical—qualities that intended users would value most in their daily operations.

Core Design Principles

The principles guiding system development and implementation

🔒

Data Privacy & Security

Supabase Auth and role-based database permissions protect account and clinic records.

💡

Evidence-Based Design

System features and architecture are based on peer-reviewed research and documented best practices in healthcare information systems (Ibrahim et al., 2022; North et al., 2024; WHO, 2021).

❤️

User-Centered Approach

Every feature is designed with end-users in mind, ensuring the system is accessible and intuitive for clinic staff with varying levels of technical expertise and patients of diverse backgrounds.

🤝

Regulatory Compliance

Adherence to Malaysian healthcare regulations including PDPA 2010, Private Healthcare Facilities and Services Act 1998 (Act 586), and MOH guidelines for Electronic Medical Records.

🌟

Quality & Reliability

Target system uptime of 99% with comprehensive testing methodology including functional testing, database validation, performance evaluation, and security testing throughout development.

🌍

Accessibility

Web-based platform accessible via standard browsers, with Google Translate integration for multilingual support, ensuring inclusivity for Malaysia's diverse patient population.

System Architecture & Technologies

Modern web technologies for reliable healthcare management

🎨

Frontend Layer

Presentation & User Interface

HTML, CSS, JavaScript for responsive web design. AJAX for asynchronous communication, jsPDF for document generation, and QRCode.js for appointment verification. Designed for cross-platform browser compatibility.

⚙️

Backend Layer

Application Logic & Processing

Supabase Auth manages sign-in. PostgreSQL functions enforce business rules, and Row Level Security limits access according to the user and clinic role.

🗄️

Database Layer

Data Storage & Management

Supabase PostgreSQL stores users, appointments, medical records, prescriptions and billing records. Legacy records retain their original IDs. Profile images use private Supabase Storage.
