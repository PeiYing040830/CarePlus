Account and data security

CarePlus uses Supabase Auth for email and password sign-in. Passwords are managed by Supabase Auth and are not stored in public application tables.

Database Row Level Security limits record access by account and clinic role. Appointment and billing changes use database functions that check permissions before updating records.

Patients can read their own records. Assigned doctors can access records relevant to their consultations. Clinic administrators manage clinic records and accounts.

Uploaded profile images use a private storage bucket. Access requires an authorized session.

For privacy questions, contact the clinic.
